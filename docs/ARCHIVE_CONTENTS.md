# ソースZIPの内容

GitHubの「Code → Download ZIP」には、アプリ本体と開発・運用に必要なファイルを含めます。除外設定は `.gitattributes` で管理します。

| 場所 | 内容 |
| --- | --- |
| `src/` | 管理者・トレーナー・会員画面とAPI |
| `public/` | アプリで使う画像・アイコン |
| `supabase/migrations/` | データベースの追加変更 |
| `database/` | 初期定義と旧版のスキーマ変更 |
| `tests/` | 自動テスト |
| `scripts/` | ZIP作成、テスト、画像生成などの開発用コマンド |
| `docs/` | この案内と契約管理の運用手順 |
| `.github/` | GitHubでの検証設定 |
| ルートの設定ファイル | 依存関係、Next.js、TypeScript、Tailwind、Vercelの設定 |

## 含めないもの

- 会員の表計算データ、Cookieファイル、実際の接続キー
- 一時的な調査・修復スクリプトとそのログ
- 古い画像の控え、テスト結果、ビルド結果、インストール済み依存関係
- 個人メモ、参考文献、事業企画資料、別プロジェクトのファイル

これらはZIPから除外します。Gitで管理済みの元ファイルや過去のコミットを削除する設定ではありません。

## 同じ形式のZIPを作る

Gitで取得した作業ディレクトリで `npm run archive:source` を実行すると、`outputs/exports/` にZIPを作成します。アプリのソースは指定したコミット（既定は `HEAD`）から取得し、作業途中の変更は含めません。除外ルールには作業ディレクトリの `.gitattributes` を使用します。

ZIP内の `SOURCE_VERSION` で元のコミットを確認できます。ダウンロードしたZIPを展開しただけの場所にはGit履歴がないため、ZIPの再作成にはGitで取得したリポジトリが必要です。
